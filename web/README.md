# Pasito Lab — веб-дашборд

Локальный SPA-дашборд для Smoant Pasito III. Отдаётся FastAPI-сервером
(`python -m pasito.cli serve`) по адресу http://127.0.0.1:8787; статика лежит в этом каталоге.

## Состав

- `index.html` — разметка дашборда (тёмная «лабораторная» тема, русский интерфейс).
- `style.css` — оформление, адаптив от 1280 px, без внешних шрифтов.
- `app.js` — вся логика одним classic-скриптом (ES2020, без модулей и сборки).
- `README.md` — этот файл.

Внешних библиотек, CDN, npm и сборки нет: всё работает офлайн в браузере.

## Что умеет

- Статус-бар: связь, имя/адрес устройства, watch, счётчик кадров, захват, последняя ошибка,
  Connect/Disconnect (`POST /api/connect`, `/api/disconnect`).
- Живой поток кадров через `WS /ws`: новые сверху, лимит 200, пауза с заморозкой таблицы
  (данные продолжают копиться), фильтр по msg, поиск по HEX, раскрытие строки с `raw_hex`
  и hexdump payload, скачивание JSONL.
- Редактор DVW: 10 полей и перетаскиваемый canvas-график, случайная/ровная кривая,
  загрузка из профиля, предупреждение о значениях вне 5–100 Вт.
- Профили: загрузка кликом, сохранение текущей кривой, переименование, удаление.
- Отправка `POST /api/send` с показом `ok`/`att_ack`/`detail`/`raw`/`read_back`
  и предупреждением о экспериментальном применении.
- Обои: темы aurora/ember/mono/minimal, живое превью
  `/api/wallpaper/preview.png?theme=…&values=…`, сохранение и применение через `POST /api/wallpaper`.

## Устойчивость

Если `/api/state` недоступен, показывается баннер «Сервер не запущен» с подсказкой
`python -m pasito.cli serve`; состояние опрашивается повторно. При обрыве WebSocket
включается экспоненциальный backoff с индикатором; таблица продолжает обновляться
через `/api/state` (поллинг раз в 4 с), поэтому падение WS не ломает интерфейс.

## Проверка

```bash
node --check web/app.js
python3 -m http.server 8899 -d web   # только статика; API будет отвечать 404 — это нормально
```

Демо-режим сервера без железа: `python -m pasito.cli serve --demo`
(эквивалент `PASITO_DEMO=1`).

## Ограничения

- Значения кривой можно ввести в 0–255 (один байт протокола), но 5–100 Вт подсвечиваются
  и предупреждаются как штатный диапазон устройства; жёсткой блокировки нет.
- Применение профиля и обоев не подтверждается протоколом — сверяйтесь с экраном устройства.
